## Clauses à exiger d'un prestataire (D13)

- Le code est poussé **chaque jour** dans le dépôt du fondateur ; aucun accès propriétaire au prestataire seul.
- Cession complète des droits de propriété intellectuelle à la société.
- Tests automatiques obligatoires pour toute règle d'argent (la CI existante doit rester verte).
- Documentation d'installation et d'API à jour ; comptes (Play Store, hébergeur, agrégateur) au nom de la société.
- Garantie de correction de 3 mois après la mise en production ; transfert de connaissances.
